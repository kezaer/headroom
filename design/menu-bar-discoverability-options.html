Repeatable entry point

Tradeoff

For later providers

My recommendation: A, with C as an entry point.

A makes the capability obvious inside Settings and provides one home for selection and order. C helps users discover it without knowing to visit Menu Bar settings first. B is worth choosing if direct manipulation is the experience you want to invest in.

One pill per chosen provider

Allow every connected, enabled provider to be shown. Use its main account. More accounts don’t silently create more pills. Available menu bar space still varies by display.

Keep choices explicit

Offer “Show all” as an action. Suggest adding newly connected providers without silently changing a user’s chosen layout. Keep the last pill until another display mode is chosen.

Don’t rearrange other surfaces

Proposed: menu bar selection and ordering should not unexpectedly move popover cards or change widget tiles. This requires revisiting today’s shared priority preference.
