04 / COMPACT, STILL USEFUL

Keep the usage signal

Fill and color still communicate usage. Exact percentages remain available when Headroom is opened.

Stable editing targets

The editing cards keep their size so dragging and removal stay easy. Only their samples and the menu bar preview become compact.

05 / DON’T GUESS THE SCREEN

A useful preview

Preview the real pill width and spacing. Avoid a simulated “fits your notch” guarantee: other apps also occupy menu bar space.

A few details that make B work

Proposed behavior to carry into the implementation plan.

Add without a hidden menu

Providers not currently shown sit in an “Available pills” area below the arranger. Add one and it appears at the right end.

Cursor+ Add pill

When every connected provider is shown, replace that area with “All 4 connected providers shown.”

One consistent display choice

Start with one global setting for percentages. Switching it should preserve providers, order, and window preferences. Existing users keep their current display choice.

Keep the preview in view

Pin the preview and Display choices above the scrolling editor if the content exceeds the Settings window. Keep all connected providers selectable; don’t impose a two-pill limit.

Still to settle in planning: independently saved menu bar order, the existing widget-priority coupling, and the last-pill removal behavior. These sketches do not add the separate connection prompt from concept C.
