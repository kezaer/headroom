More providers, better account control

  • Grok and Cursor are here. Headroom now shows subscription usage from Grok and Cursor alongside Claude and Codex, using each provider's official CLI.
  • Choose your Main account. Make any tracked Claude, Codex, or Grok account the one Headroom uses for the menu bar, widgets, and phone sync.
  • Recover setup without getting stuck. Stop waiting on an abandoned Terminal handoff, then retry setup or continue managing the account.
  • Manage built-in CLI accounts safely. Sign out and set up again, or stop tracking a built-in account without deleting its CLI-owned login.
