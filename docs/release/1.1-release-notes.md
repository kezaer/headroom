# Headroom 1.1 Release Notes

Headroom 1.1 adds multiple Claude and Codex subscription accounts while keeping every sign-in in
the official provider CLI. Each provider can show up to five accounts with isolated local config
homes, account-scoped refresh and recovery, honest removal states, and compact scrolling layouts
for larger account sets. The menu bar, widgets, and iPhone companion continue to follow the
built-in account for a stable at-a-glance meaning.

Provider setup is more resilient and explicit: Claude login, workspace trust, missing CLI, and
transient panel states remain distinct; Codex setup now distinguishes missing, rejected,
permission-blocked, unsafe, malformed, callback-incomplete, and storage-mismatch outcomes. Guided
recovery stays on official CLI commands, includes standard and device-code Codex login, and never
uses Claude subscription OAuth credentials.

API Spend settings now include direct Anthropic and OpenAI top-up links. This release also improves
setup accessibility, focus return, Reduce Motion behavior, retry scheduling, and the high-account
popover density while preserving primary-only projections to compact surfaces.
