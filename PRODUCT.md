# Product

## Register

product

## Users

Pacemark helps people check their AI subscription usage from the Mac menu bar while they work.

## Product Purpose

Pacemark shows remaining AI-subscription usage, reset timing, renewal context, and optional API spend without exposing credentials or making users open provider dashboards. Success means the user can answer "how much room do I have left?" in a few seconds, with every provider presented as a peer in the menu bar and popover.

## Brand Personality

Quiet, precise, premium. The interface should feel native and calm, with enough craft to feel considered but not enough decoration to distract from usage data.

## Anti-references

Avoid marketing-site gloss, decorative glassmorphism, provider-tinted card surfaces, heavy borders and overly elevated cards. Claude and Codex cards should use the same material system; provider color belongs in iconography, labels, and usage bars only.

## Design Principles

1. Make comparison feel fair: Claude and Codex are sibling data objects, so their containers should not imply different status unless the data itself differs.
2. Preserve native restraint: use system-like materials, shadows, and spacing that sit comfortably on macOS.
3. Optimize for glanceability: percentages, reset labels, and freshness should be legible before the user studies the UI.
4. Share decisions across surfaces: the popover, menu bar and Settings should reuse tokens and visual techniques whenever the interaction model allows it.
5. Let alerts be explicit: stale, pending, or attention states should use clear state treatments, not accidental material differences.

## Accessibility & Inclusion

Prioritize legibility in light and dark modes, maintain high contrast for labels and percentages, avoid relying on provider color alone for meaning, and respect reduced-motion settings.
