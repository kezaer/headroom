# Brand Icon Sources

These source SVGs are bundled for provider identity in UsageBar's UI.

- `claude-color.svg`: LobeHub static SVG icon package, `claude-color` icon. LobeHub lists the official site as `https://claude.ai`.
- `codex-color.svg`: LobeHub static SVG icon package, `codex-color` icon. LobeHub lists the official site as `https://openai.com/codex`.

OpenAI's brand guidelines say to use OpenAI marks only when directly related to OpenAI services, to follow their style guides and usage terms, and not to imply endorsement. UsageBar uses the Codex mark only to identify the user's own Codex/ChatGPT usage source.
