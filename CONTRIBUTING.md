# Contribute to Pacemark

Report bugs and discuss changes in [Pacemark issues](https://github.com/kezaer/pacemark/issues). Include the app version, macOS version, provider and steps to reproduce. Remove account identifiers and credentials from logs and screenshots. Use the [security reporting process](SECURITY.md) for vulnerabilities.

Read the [developer guide](AGENTS.md) before changing code. For a new integration, describe the official client's usage read in the issue and follow the [provider guide](docs/adding-a-provider.md). Include verification results with your pull request.

Contributions use the same [GPL-3.0 license](LICENSE) as Pacemark.
